Moving from Activity 10 to Activity 11 really showed me the power of React’s component-based architecture. In my vanilla JS version, functions were scattered and manually tied to the DOM, but React organizes the code into reusable components like Square and Board, which makes the project much easier to maintain. State management is also significantly simpler because using the useState hook allows React to handle UI updates automatically, whereas in Activity 10, I had to manually write functions to update innerText every time a variable changed. React’s use of the Virtual DOM is a huge benefit here because it efficiently handles these updates without me having to target specific HTML elements.

Adding features like time travel really highlighted React’s advantages. In vanilla JS, tracking a full history of moves would have required complex array management and significant DOM refactoring. In contrast, React’s one-way data flow and immutability (by using .slice() to copy state) made it easy to jump between previous game states. While lifting state up was a challenging concept to grasp at first, I now see how it makes data flow much more predictable. For my next steps, I’m excited to learn about the useEffect hook for handling side effects and exploring modern build tools like Vite to move beyond simple CDN links.
